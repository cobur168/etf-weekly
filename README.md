## 核心指标：溢价率

场内 QDII ETF 因 QDII 额度受限、套利机制不畅，常出现**显著溢价**。溢价买入相当于预付了未来若干年的管理费，且溢价回归时会直接损失本金。

```
溢价率 = 场内收盘价 ÷ 基金单位净值 − 1
```

例如溢价 15%，意味着花 115 元买到净值 100 元的份额；溢价一旦回归 0，直接损失 13%。
